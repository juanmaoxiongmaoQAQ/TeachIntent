# Third-party provenance and redistribution boundary

TeachIntent is a personal open-practice application, not an official Tencent
release. Its own source is provided under the repository's [MIT license](../LICENSE).
That license does not replace licenses or terms for external code, model
weights, hosted services, reference recordings or generated media.

| Component | Role and provenance | Distribution boundary |
|---|---|---|
| Tencent Hy3 | Live pedagogical planner requested as `tencent/hy3`; provider/model provenance is recorded with outputs. | Accessed through the configured server-side client; no Hy3 weights included. |
| [Tencent digitalhuman / BatonVoice](https://github.com/Tencent/digitalhuman/tree/main/BatonVoice) | Optional reference execution backend. The local upstream README identifies this repository and its Qwen3/CosyVoice2/Matcha-TTS dependencies. | External installation selected by `BATONVOICE_SOURCE_DIR`; no upstream source or checkpoints vendored by this release work. |
| [CosyVoice](https://github.com/FunAudioLLM/CosyVoice) | Existing CosyVoice2 checkpoint used by the Baton runtime. | Selected through `BATONVOICE_COSYVOICE_MODEL_DIR`; review the exact checkpoint's terms. |
| WeText processing/FST assets | Local text-normalization assets for Baton execution. | Selected through `BATONVOICE_WETEXT_FST_DIR`; not bundled. |
| [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) | Earlier optional renderer; actual source of the published Explore A/B audio. | `public_demo/voice/*/v0_2/manifest.json` identifies `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, speaker Vivian, exact text/hash, seed, instructions and WAV hashes. |
| OpenRouter | Configurable hosted planning client and separately triggered Judge access. | API keys stay in the server environment; service access is not included in the source license. |

The existing audio manifests are preserved; Qwen recordings must not be relabeled
as Baton recordings. Supportive feedback has an empty delivery plan and identical
neutral/planned WAV hashes. The public evaluator artifacts preserve their own
run/version and input/plan hashes separately from the speech manifests.

The project owner confirmed on 2026-09-14 that the six existing Explore WAVs
are synthetic demonstration audio generated by the project, approved for the
TeachIntent public demo. They contain no real participant recordings or private
user data. Their original files and provenance manifests are retained unchanged.
This statement covers those demo outputs; it does not relicense external models
or source code. Review the terms for any separately distributed third-party
code or checkpoints. The manifests identify provenance, not a blanket permissions
grant. Any local Baton reference
prompt WAV supplied via `BATONVOICE_PROMPT_AUDIO_PATH` requires the owner's
appropriate permission and is not added by this release work.

No model was downloaded or trained, no upstream or site-packages file was
modified, and no new speech artifact was generated during release hardening.
