# 两分钟产品演示

按 [快速开始](../README.md#快速开始) 启动网页。以下流程只使用已有公开示例，
无需 API key、模型或 GPU，也不会发起生成、检查或渲染请求。

| 时间 | 页面与操作 | 讲解重点 |
|---|---|---|
| 0–20 秒 | 首页 | 输入教学内容、学生状态与教学意图，规划“说什么 + 怎么说”。 |
| 20–50 秒 | 示例库 → 纠错反馈 | 回应学生对速度方向的误解，表达提示附着在对应教学步骤。 |
| 50–75 秒 | 计划质量检查 → 查看详细评价 | 六维检查针对计划，原始证据保留在展开区，不评价音频。 |
| 75–95 秒 | 切换支架与支持性反馈 | 教学意图改变帮助方式；无需控制时不会凭空增加语音指令。 |
| 95–110 秒 | 已有 A/B 音频 | 手动播放基础语音或规划后语音，说明它们是 Qwen3-TTS 记录。 |
| 110–120 秒 | 在线体验 → 使用示例 | 只填入表单；实时生成、质量检查和可选语音均由用户另行触发。 |

高级对比入口在在线体验与示例库底部，保持输入条件不变，仅改变意图。
三份现成案例的教学情境不同，因此不能称作严格的意图对照实验。
技术详情默认折叠；演示无需暴露版本、错误、模型路径或其他工程信息。

如需录屏，保存到忽略的 `outputs/`，不要包含密钥、私人路径、参与者信息。
本项目是个人开源实践，不是 Tencent 官方发布；示例结果不证明实际学习效果。
